GATE Git 管理门禁 · 跨切（改源码能力 0/C/1/4/5/6/8/9 自动包裹）
references/capabilities/git-gate.md
  • 无 .git → auto-init + .gitignore + 基线提交
  • .git 在根 + 脏 → 复用 + 未提交改动提交为基线
  • .git 在根 + 干净 → HEAD 即基线，跳过
  • .git 在祖先 → 门禁不介入，能力照常跑
  • 能力提交 scope：(ds-act-workflow) · 可 git log --grep 追溯
  • 只读 / gitignored 产物能力（2/3/7）不触发门禁
  • 幂等重入无改动 → 跳过提交（不产空 commit）
  • 中途失败 → partial 提交 + [中断] 标注，不自动回退
