## Context

互动游戏广告将小游戏嵌入客户端 WebView，上下被客户端原生 UI 遮挡（顶部状态栏 + 集数/倍速导航栏，底部广告下载面板）。这些遮挡区不可点击。运营拿到第三方/自研的全屏小游戏 HTML 后，需要一个可视化"标尺"来确认核心玩法没被遮住，并据此把游戏内容收进安全区。

ds-act-workflow 现有模式 0/C/1-7 各司其职，审查链由 `references/audits/index.md` 统一编排，遵循 marker 锚定 + 分级阻断（🔴 阻断 / 🟡 警告）的既有约定。本设计在此框架内新增模式 8。

美术稿实测参数：上遮罩 height 94px，下遮罩 height 220px，宽均 100vw。

## Goals / Non-Goals

**Goals:**
- 提供 mode 8，可一键往任意小游戏 HTML 注入/移除上下两块调试遮罩。
- 遮罩贴屏幕边缘、吃掉点击，真实还原客户端遮挡。
- 注入物用 marker + 唯一 class 双重锚定，移除可精准、无残渣。
- 添加遮罩后记录安全区标尺（写 CLAUDE.md）并输出可复制的适配 prompt。
- 残留遮罩检查接入主审查链，调试遮罩绝不带上线。

**Non-Goals:**
- 不自动改造游戏布局去适配安全区（那是运营 + AI 的事，本模式只给标尺和 prompt）。
- 不在 mode 0-7 任何流程主动提适配、主动注入遮罩或主动弹 prompt。
- 不做生产态占位 UI（遮罩是纯调试标尺，方案 A）。
- 不支持运营自定义遮罩高度的参数化交互（固定 94/220，保持标尺一致性）；背景图 url 可选。

## Decisions

**D1 — 固定命名采用 marker + class 双锚点。**
marker `<!-- [DS:AD-PREVIEW-COVER:START] -->` / `END` 包裹注入区，class `ds-act-ad-preview-cover` + 修饰符 `--top` / `--bottom`。
- 理由：marker 便于整块删除与审查正则锚定，沿用 skill 既有 DS marker 风格；class 提供 CSS 钩子且语义唯一（`ds-act-` 前缀避免与业务样式冲突）。
- 备选：仅用 class（删除时难界定边界，易误删）；仅用 id（无法表达上下两块的同源关系）。均不如双锚点。

**D2 — 遮罩吃掉点击，不用 `pointer-events: none`。**
`position: fixed`、`top:0`（上）/ `bottom:0`（下）、`width:100vw`、`z-index` 取高值、`pointer-events:auto` + `touch-action:none`。
- 理由：目的是模拟"客户端 UI 挡住游戏使其不可操作"，必须真实拦截点击/触摸。用 `none` 会让点击穿透，与目标相反。

**D3 — 背景图可选，缺省半透明红框兜底。**
运营提供 bgUrl 则 `background-image` 还原真实视觉；不提供则半透明红色 + 边框，呼应美术稿红框，仅作标尺。

**D4 — 标尺记录写入项目 `CLAUDE.md`。**
追加"## 互动广告安全区（调试标尺）"节，记录顶部 94px / 底部 220px / 可操作区 `calc(100vh - 314px)`。
- 理由：CLAUDE.md 是 skill 既有的项目约定文件（mode 0 已写入约定），后续 AI 会话读得到，是适配的天然参照。
- 备选：单独建文件（增加散落产物，不如复用既有约定文件）。

**D5 — 适配 prompt 即时输出，仅在添加遮罩后。**
输出一段可复制文本，告知顶部 94px / 底部 220px 不可点击，要求把核心交互收进 `calc(100vh - 314px)`，遮挡区只放装饰。

**D6 — 触发边界硬约束。**
适配引导（标尺 + prompt）只在 mode 8「添加遮罩」子操作触发。残留阻断检查则始终挂主审查链，但它只做"扫到残留→提示删除→阻断"，不反向引导适配。两者性质分离，互不越界。

**D7 — 审查规则作为"始终触发"项接入 `audits/index.md` 加载清单。**
不同于小程序/导航栏等条件触发规则，遮罩残留检查无条件扫描所有 HTML —— 因为残留遮罩任何项目都不该上线。

## Risks / Trade-offs

- **[运营忘记移除遮罩直接上线]** → 主审查链无条件扫描 marker/class，发现即 🔴 阻断，mode 3 部署前必经审查。
- **[班级 class 与业务样式冲突]** → 统一 `ds-act-ad-preview-cover` 前缀 + marker 包裹，命名空间足够唯一。
- **[固定 94/220 与未来不同广告版式不符]** → 当前以美术稿实测值为准；若后续出现新版式，再以新 change 扩展参数，不在本次范围。
- **[CLAUDE.md 重复追加标尺节]** → 写入前先检测是否已存在"互动广告安全区"节，存在则覆盖更新而非重复追加。
- **[mode 8 之外误触发适配引导]** → 在 spec 与 reference 中以显式 Scenario 固化"仅 mode 8 触发"，审查阻断逻辑明确不含引导文案。
