# P2 道具经济平衡表 · 设计说明（props_notes）

> 配套数据文件：`props_economy.csv`（4 道具 × 10 列，双玩家档口径）。本文件解释测算口径、平衡逻辑、调参旋钮与反滥用细则，供开发与运营参考。
> 版本：v2.2 · 历史经济测算，对应《玩法设计文档》v3.4。v3.5 已扩为 200 关并把当前加时改为“每关首次免费 +15 秒、二次任务视频”；本表所有按 100 关计算的供需量均已失效，开发四道具前必须按 `levels_200.csv` 重跑。
> 测算脚本：`_p2_calc.py`（改参数后运行即可复算并回写 CSV）

## 二、两档玩家日关次推算（体力新经济 D11）

**口径**：日关次 =（日眼力供给 − 无尽入场 − UGC 游玩）÷ 每关 1 眼力。无尽入场 5/局，UGC 游玩 1/次（D19）。初始/上限均为 20；每日首次登录补到 20，不是固定 +20（D24）。

### 无视频玩家（NV）：设计中心 40 关次/天（区间 35~45）

| 项目 | 量 | 假设 |
|---|---|---|
| 首次登录可用存量 | 20 | 先结算离线恢复，再按 D24 补到 20；这是登录后的可用余额，不是固定发放 +20 |
| 在线恢复 | +15~25 | 日均在线 45~75 分钟 ÷ 3 分钟/点（游玩中也恢复，单局约 1.2 分钟含结算，40 关 ≈ 48 分钟 + 无尽/菜单） |
| 离线恢复 | +3 | 白天碎片化离线 >5min 部分累计约 3 小时 |
| UGC 有效完成奖励 | +5 | 日均由另一有效账号首次完成 1 次（日限 3 用不满，D26） |
| **供给合计** | **43~53** | |
| 支出：无尽 1.5 局 + UGC 1.5 次 | −9 | 无尽 5/局 × 1.5；UGC 1/次 × 1.5 |
| **关卡可用** | **34~44 ≈ 35~45** | 与 v2.5 完整版本设计区间吻合 |

### 看视频玩家（V）：设计中心 65 关次/天（模型 55~75，运营目标 60~75）

| 项目 | 量 | 假设 |
|---|---|---|
| 首次登录可用存量 | 20 | 同；按登录后余额建模，不把「补到 20」误算成固定 +20 |
| 在线恢复 | +25~30 | 日均在线 75~90 分钟 ÷ 3 |
| 离线恢复 | +3 | 同 |
| UGC 有效完成奖励 | +5~15 | 另一有效账号首次完成 1~3 次，日限 3（D26） |
| 看视频回体力 | +15~20 | D16 入口①：体力耗尽即看，日均 3~4 次 × 5（30s/个，合计看片 ≤2 分钟，意愿可承受） |
| **供给合计** | **68~88** | 20 + (25~30) + 3 + (5~15) + (15~20) |
| 支出：无尽 2 局 + UGC 3 次 | −13 | |
| **关卡可用** | **55~75** | 设计中心约 65；运营目标带 60~75，低位玩家可能落到 55 |

> 体力视频按 D24 每日最多计奖 4 次，因此供给上界为 +20，不再依赖「玩家看片意愿」作为唯一约束。若完播率低于模型假设，V 档 N 会下移，按 §四敏感度表复核。

## 三、视频通道分流假设（沙漏消耗重算核心）

- **加时总需求率不变**：8% 的局需要加时（卡关救场 + 三星冲刺），平均 1.15 次/局——行为基线沿用旧版，因为「需要加时」的场景结构没变，变的是**由谁供给**。
- **NV 档**：无视频通道，加时需求 100% 由沙漏存量承担 → 消耗 = N × 0.08 × 1.15。
- **V 档分流假设：70% 的加时需求被免费视频通道吸收，30% 落到沙漏存量**。落到存量的场景：通勤/弱网无法加载视频、不愿打断心流、连打多局时看片疲劳、存量充足懒得看。
  - 分流 70% 的依据：视频加时零库存成本、与沙漏同区间同上限，理性玩家默认先看视频；30s 时长对「就差几秒」的救场场景可接受。该值是**本表最大不确定参数**，上线后应以「视频加时次数 ÷（视频加时 + 沙漏使用次数）」实测校准——若实测分流 >85%，V 档沙漏消耗趋近于 0，需重新评估沙漏定位。
- **共享上限**：视频加时与沙漏合计每关 ≤3 次。沙漏的 1.15 次/局平均用量与视频的用量之和受 ≤3 硬顶约束，本模型平均用量远低于上限，硬顶只影响极端局，不改变日均值。

### 🔍 放大镜（免费服务型，弱经济）
- **免费额度**：每局 1 次 × N 局供给，使用率约 40%，不可结转，无通胀风险（沿用旧结论）。
- **存量获取**：小章通关 +3/章（10 小章共 30 个一次性），推进期 NV 35 天 / V 25 天摊销 → NV 0.86、V 1.20；V 档叠加 D16 入口③ 卡关视频换 +1（日均 0.3 次）→ **1.50**。
- **存量需求**：高难局 6% 需第 2 次提示 + 普通局 0.5% → NV 0.86、V 1.40。
- 两档比率 100%/107%，从旧版 85% 的小缺口转为**微盈余**——D16③ 新增来源所致。放大镜本就是弱经济道具，盈余无害；若存量淤积（上限 10），说明免费额度已够用，入口③ 的拉看视频效果自然受限，无需干预。

### ⏰ 时光沙漏（重新定位：免看视频的「立即加时」）
- **NV 档（71%）**：获取 2.63 = 首三星 2.0 + 一次性 22 个/35 天 0.63；消耗 3.68 = 40 × 0.08 × 1.15（无视频通道，全部存量承担）。**缺口 29%**——比旧版 84% 更深，原因有二：移除日限 2 可重复来源、N 下降但一次性来源摊销变厚不足以对冲。缺口即压力：NV 玩家要么省用存量，要么转为看视频——这正是 D16 导流设计的预期行为。
- **V 档（206%）**：获取 3.68 = 首三星 2.8 + 22/25 0.88；消耗被视频分流 70% 后仅 1.79。**结构性盈余**——看视频玩家用不上沙漏，存量向 10 上限堆积。设计解读：沙漏成为「无网场景备用金」，溢出丢弃 + 提示背包已满（见 §五通用-2）即可；不建议为消化盈余新增消耗口，那会反过来削弱视频导流。
- **毕业后（两档共性）**：122 个一次性来源枯竭后获取归零，需求仍在 → 沙漏退化为纯限量资产，加时需求最终全部由视频通道承接。这是 v2.4 的**预期终局**，不是失衡；若运营希望保留长尾沙漏循环，用旋钮「每日任务 +1」（见 §六）。

### ❄️ 冻结怀表（无尽专属产出，无视频替代通道）
- 视频通道只提供加时与放大镜，**怀表无替代品**，需求结构不受 D16 影响，只随 N 缩放。
- **获取**：无尽第 5/10 波各 +1（达成率 0.9/0.5，局均期望 1.4 个），NV 1.5 局/天 → 2.10；V 2 局/天 → 2.80，均未触每日上限 3（上限是防高手刷波的保险丝，不是日常约束）。
- **需求**：刷星回炉局 15% + Boss/高难冲刺 18% → NV 2.59（81% ✓）、V 4.21（67%）。
- **V 档 67% 低于 80% 目标**：重度玩家回炉/冲刺局多，但怀表日获取被「局数 × 1.4」与每日上限双重封顶。判定为**有意的定向压力**——想多怀表就得多打无尽（无尽入场 5 眼力又回收了视频多发的体力，形成闭环）。若数据显示挫败，旋钮见 §六-2。
- 第 60 关前无尽未解锁，怀表无来源无消耗，属前置稀缺（沿用旧结论）。

### 🗺️ 鸟瞰眼镜（首通日课）
- **获取**：每日首次通关 +1（NV 达成率 95% / V 98%）。公开图鉴与主题集齐奖励已取消，开发前需据此重算供给比。
- **需求**：高难迷路 7% + 极速找方向 4% → NV 0.92、V 1.50。
- **NV 档 122% 盈余**：日课供给是定额（+1/天），不随 N 缩放，而需求随 N 下降——低关次档下固定滴灌天然盈余。无害（上限 5 兜底，溢出丢弃）；若运营想压回 80%，改「每 2 日首通 +1」即可（122%→61%，需配合存量缓冲观察）。
- 当前不设置图鉴解锁门槛；若需要中期开放，改用明确关卡进度门槛另行评审。

## 五、反滥用细则（逐道具）

### 通用
1. **无尽模式禁用全部 4 种道具（D6 正式决议）**：无尽有独立的时间银行与榜单（无尽榜只吃伙伴加成），道具入无尽会破坏波次平衡与榜单公平。怀表为「无尽产出、关卡使用」，获得渠道与使用场景分离，不违反 D6。
2. 存量满时获取：溢出部分**丢弃并提示「背包已满」**（不做延期领取，防止变相囤积）。
3. 所有道具的获取与消耗写本地日志，纳入 §7 防作弊框架；关键判定（三星、波次、通关）以本地持久化/未来服务端记录为准，防篡改。
4. 每日类计数（日限、首通奖励）按自然日 0 点重置（D15：每日上限仅用于消耗品防刷，不与永久进度挂钩）。

### 🔍 放大镜
- 免费次数**当局有效、不结转**下一局；单局持有（免费 + 存量补足）合计 ≤ 3 次（§3.3 原规则）。
- 同一目标已被高亮后再次使用**不重复消耗次数**；目标全部找到后按钮置灰。
- D16 入口③「卡关看视频换 +1」建议触发口径（供开发参考）：单关已耗时 ≥ 总时长 50% 且仍有 ≥2 个目标未找到时入口出现；兑换入存量、受存量上限 10 约束。**此触发口径为本表建议，需主文档或开发侧确认。**

### ⏰ 时光沙漏
- **与视频加时共享上限：视频加时与沙漏合计每关 ≤3 次**；剩余时间满格（≥ 本关总时长）时**沙漏与视频加时两个入口都置灰**；加时后超总时长满格截断（沿用谜字坊规则）。
- 「每关首次三星 +1」**按关卡 ID 记录、终身一次**：重复刷同一关三星不重复给（契约既定规则）。
- 同一局内多次使用均固定 +15s；视频与沙漏共享每关 3 次上限，不再使用随机区间。
- 沙漏不豁免点错惩罚：加时只是续命，点错 −3s 与连击清零照常。

### ❄️ 冻结怀表
- **冻结只暂停自然计时流逝，不豁免点错惩罚**：冻结 5 秒内点错仍 −3 秒（否则冻结 = 5 秒无风险乱点，破坏双罚设计）。
- 每关 ≤ 1 次，天然不可叠加；冻结期间再次使用不可用。
- 无尽获取按**波次里程碑**结算：第 5/10 波各 +1，中途超时按已达成的里程碑发放（到第 8 波超时 → 得 1 个）；每局上限 2、每日上限 3，跨日不累计。

### 🗺️ 鸟瞰眼镜
- 展示 2 秒内**点击锁定且计时照常**——全景观摩而非免费暂停。
- 解锁资格（集齐 2 主题）为**永久判定**，一旦解锁不回溯。
- 「每日首次通关 +1」日限 1，**「通过」口径 = 找齐全部目标**（超时局不算，与 v2.4 超时口径契约一致）；「每主题 +1」按主题 ID 记录、一次性，默认不随赛季重置。

## 六、运营期可调旋钮（按敏感度排序）

| 旋钮 | 当前值 | 调整方向与影响 |
|---|---|---|
| 视频分流系数（观测值，非配置） | 假设 70% | 实测偏离时重跑 `_p2_calc.py`（改 `HG_VIDEO_SPLIT`）；实测 >85% 时 V 档沙漏名存实亡，需重估定位 |
| 怀表无尽每日上限 | 3 | →4：V 档玩家打满 3 局无尽时比率 67%→95%；若怀表贬值则反向 →2 |
| 沙漏长尾来源 | 无 | 加「每日任务 +1」：NV 比率 71%→98%，但削弱视频导流，慎开 |
| 鸟瞰首通滴灌 | +1/天 | NV 盈余淤积时改「每 2 日 +1」；供不应求时 →2（V 档 81%→163%，配日限） |
| 小章奖励（放大镜） | +3/小章 | 新手期缺提示 →4；毕业后无来源属预期 |
| 存量上限 | 10/10/5/5 | 上调 = 拉长缓冲、减弱缺口压力；下调反之 |
| 每关使用上限 | 3（合计）/3/1/1 | 商业化阶段不建议动，直接影响单局平衡与计分公平 |
| 商业化接口 | 视频即变现（D16） | 礼包售道具时售价锚定「免看 N 个视频」：沙漏 ≈ 免看 1 个 30s 视频 + 立即生效 |
| 溢出转化 | 丢弃 | 可改为「溢出转眼力值 1:1」，缓解 V 档沙漏溢出挫败 |

## 七、毕业后（100 关三星齐）长线形态

| 道具 | 毕业后获取 | 毕业后需求 | 形态 |
|---|---|---|---|
| 放大镜 | 仅 D16③（V 档 0.3/天） | 低（免费额度为主） | 免费额度兜底，存量自然消耗至低位平衡 |

## 八、需要主 agent 注意 / 跨表协调项
