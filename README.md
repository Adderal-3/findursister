# 忙忙碌碌寻宝藏

一款移动端竖屏古风属性寻物 H5。玩家在单屏完整画面里，根据“乐器、会飞、陶瓷、圆形、食物但不是甜食”等线索，找出全部正确物件。

## 当前版本

- 123 件透明 WebP 古风物件、30 条单标签/交集/并集/排除任务。
- 200 关主线：L1~3 单目标教学、L4~40 双目标、L41~200 三目标。
- 10 个篇章，每篇 20 关；9 道星门控制长期进度。
- 目标栏同时展示已完成、当前与下一项目标；阶段完成会明确提示下一项。
- 局内采用移动端单屏画布，物件基准尺寸为短边 20.5%；主体完整装箱，不互相压叠，也不会再被初始镜头左右切断。
- 本关首次点击“加时”免费 +15 秒；再次点击进入任务视频流。任务奖励回调入口已经预留，平台任务仍待配置。
- Web Audio 正确/错误/提示/结算音效，首次局内点击会同步解锁音频；局内带持久化静音按钮。
- BGM 接口已预留：配置 `VITE_GAME_BGM_URL` 后自动循环并受静音按钮控制。
- 8 位伙伴；未获得时不显示姓名与头像，只显示获得方式和当前进度。
- 日榜/总榜双页签；榜单计算说明移到游戏说明，不在榜单页面占位。
- 大神 JSSDK、登录、分享、导航、任务面板与 DataHub 均支持“未配置时安全降级”。

## 一局怎么玩

1. 顶部任务轨道会标出当前目标和后续目标。
2. 在完整单屏画面中观察并轻点物件，不需要横向拖动画面。
3. 轻点符合属性的物件；一件物品可以同时拥有多个属性。
4. 首次进入时会一次展示完目标、连击、计分、加时、静音与提示规则，后续教学关不再反复弹窗。
5. 当前目标完成后会显示“已完成 / 下一项”，场景、时间、分数和连击连续保留。
6. 找错物件或点空白区域会扣 3 秒并清空连击；找齐全部目标即可过关。

## 计分与排行榜

### 单局原始分

- 单次命中分 = `剩余时间 × 连击倍率`，保留 0.1 分。
- 连击倍率从 1.0 开始，每次 +0.1，10 连击封顶 1.9。
- 每关星级仍使用原始分与关卡表 `star2` / `star3` 比较。

### 标准榜分

为避免后期多目标关仅因物件多而天然权重更高，每关历史最好会转换为等权标准分：

```text
单关标准榜分 = round(min(1.2, 本关历史最好原始分 / 本关理论满分) × 1000)
总榜基础分 = 所有已完成关卡的单关标准榜分之和
总榜最终分 = round(总榜基础分 × (1 + 伙伴人数 × 1.25%))
```

单关标准榜分通常为 0~1000；使用加时或超越理论节奏时最高计 1200，防止无限放大。

- 日榜：当日每个不同关卡只保留一次最高原始分，再转换并求和；不吃伙伴加成。
- 总榜：历史每关最高标准榜分求和；伙伴加成从获得时起实时生效。
- 日榜字段：`levels_daily_score`。
- 总榜字段：`levels_total_score`；审计字段为 `levels_base_score` 与 `partner_bonus_bps`。

日榜自然日重置和正式排名需要大神后台配置；当前本地存档先按设备本地日期记录。

## 分类调整流程

打开 [物品分类调整对照表](./tools/item-classification-review.html)：

1. 搜索并检查 123 件物品；
2. 点击“调整分类”，修改五类标签并填写备注；
3. 导出 `物品分类调整.json`；
4. 把 JSON 交给 AI，批量更新 `src/game/items.ts`；
5. 运行 `npm run catalog`、`npm run catalog:review` 和 `npm run check`，同步任务候选池与关卡校验。

只读关系总表仍保留在 [物品属性关系表](./tools/item-relations.html)。

## BGM 接入

1. 把音乐放到 `public/audio/bgm.mp3`；
2. 在环境配置中设置：

```text
VITE_GAME_BGM_URL=/audio/bgm.mp3
```

音乐会在用户首次交互后开始循环，音量默认 32%，并自动跟随局内静音按钮。

## 本地开发

```bash
npm install
npm run dev
npm run check
```

常用命令：

| 命令 | 用途 |
|---|---|
| `npm run assets` | 重新处理生产物件素材 |
| `npm run ui:warm` | 重新生成暖色 UI 切片 |
| `npm run levels` | 重新生成 200 关配置 |
| `npm run catalog` | 生成只读属性关系表 |
| `npm run catalog:review` | 生成可编辑分类对照表 |
| `npm run verify:content` | 校验素材、分类、任务和 200 关 |
| `npm run check` | 内容校验、ESLint、TypeScript 与正式构建 |
