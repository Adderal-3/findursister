# 忙忙碌碌寻宝藏

一款适配移动端的古风属性寻物 H5。玩家在可拖动的大场景里，根据“会飞的、会发光的、乐器、动物”等属性线索，找出全部正确物件。

## 当前版本

- 123 件去重后的古风物件，全部使用透明 WebP 正式素材。
- 保留原有 10 类属性，并增加食物、水果、蔬菜、穿戴物、桥梁、材质与外观等多维标签。
- 100 关闯关模式：L1~3 单目标教学、L4~40 双目标、L41~100 三目标；同关目标逐个揭晓。
- 无尽模式：按波次生成单标签、材质/外观、交集、并集与排除任务。
- 眼力值体力：上限/初始 20，百关每关 1、无尽每局 5，在线每 3 分钟恢复 1，支持离线结算与每日补满。
- 1.6 屏紧凑横向场景与无重叠装箱：同一关的全部物件一次生成，细长物件会额外放大，后期最多 12 个目标。
- 可拖动的大场景、提示镜头、连击计分、三星结算与本地存档。
- L1 拖动、L2 连击、L3 计分教学；每段只自动出现一次并支持跳过。
- 百物图鉴：目标物件首次命中后永久点亮。
- 大神 JSSDK、登录、分享、导航和任务面板的既有适配保持不变。

## 玩法

1. 观察顶部当前唯一展示的属性目标，例如“乐器 0/2”。
2. 按住并拖动画面探索完整场景。
3. 轻点符合属性的物件；一件物品可以拥有多个属性。
4. 完成当前目标后，顶部再揭晓下一个；场景、计时、分数与连击保持连续，全部完成后过关。点击错误物件或空白区域会扣 3 秒并清空连击。

## 素材体系

素材来自 `逆水寒07小游戏素材-页面 1.zip` 和 `download (11).zip`。生产版本按画面与语义去重为 123 件（原有 87 件 + 新增 36 件），并自动完成：

- 裁掉透明空白；
- 统一为 256×256 正方形画布；
- 主体控制在 224×224 安全区内；
- 转为 WebP；
- 使用稳定英文文件名。

生成后的素材位于 `public/items/ancient/`，总体积约 1.87 MiB。重新处理素材：

```bash
npm run assets
```

物品名称与多属性标签维护在 `src/game/items.ts`。详细规则见 [素材替换说明.md](./素材替换说明.md)。

## 本地开发

```bash
npm install
npm run dev
npm run check
```

常用命令：

| 命令 | 用途 |
|---|---|
| `npm run assets` | 从两个原始 zip 重新生成 123 张生产素材 |
| `npm run ui:warm` | 从原始 UI 切片重新生成暖色透明按钮与任务框 |
| `npm run levels` | 重新生成十分类 100 关数值表 |
| `npm run verify:content` | 校验素材、物品表、分类与关卡完整性 |
| `npm run lint` | ESLint 检查 |
| `npm run build` | TypeScript + Vite 正式构建 |
| `npm run check` | 执行完整内容、代码与构建检查 |
